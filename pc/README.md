# Protea PC

The PC platform is the first complete device path.

The initial PC implementation will run on Linux as a user session before becoming part of a bootable Protea system.

Planned components:

- shell
- taskbar
- application/start surface
- settings integration
- mode controller
- session bootstrap
- hardware/profile integration

The PC shell must consume the shared-core contracts rather than creating a separate settings/account model.
